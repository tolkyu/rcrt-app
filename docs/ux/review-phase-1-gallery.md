**2026-11-03 · CHANGES REQUESTED.** Scope: all 128 PNGs and the captions in `screenshots/phase-1/index.html`, plus `screenshots/foundation/` (4 PNGs). ## Summary

| Severity | Count | Meaning |
|---|---|---|
| P1 | 2 | Blocks the owner demo: the gallery does not show what the owner will log in to |
| P2 | 10 | Fix in Phase 1 (a11y failures, misleading data, mobile, copy on dead-end pages) |

Verdict: the Admin settings screens look consistent and calm in both themes, and the copy is natural Ukrainian. There are two blockers. First, the gallery shows only Admin and public screens: 6 of the 7 roles and 4 built routes have no screenshot. Second, screenshots from different fixtures contradict each other.

## Already good
- Calm, consistent layout. Spacing follows the 4 px scale; page title/subtitle hierarchy and the radius 16 cards match the design system in both themes.
- Dark theme: no washed-out text. Muted text (#94A3B8), input borders and the `--link` indigo all pass AA. DENIED chip, warning text («Прострочене з …») and destructive-soft buttons stay readable.
- Destructive flows all use AlertDialogs that state the consequence (revoke, remove roles, deactivate). The deactivate partial-failure state reads clearly; its secondary button changes to «Закрити».
- Mobile dialogs are bottom sheets with stacked 48 px buttons in the agreed order (Скасувати above confirm). Earlier fixes P1–P5 hold, including emails breaking before «@» and no hyphenation.
- The copy is natural and professional. Apostrophes are `ʼ` (0 ASCII `'` or `’` in `uk.json`). Dates use uk-UA `dd.MM.yyyy, HH:mm` with «(Київ)» + UTC in the audit detail. No untranslated UI strings outside the allowlist.
- Seeded people's names are realistic Ukrainian names. No lorem ipsum.
- The priorities screen explains equal priorities, the «Без пріоритету» group, unsaved diffs and the concurrent-change conflict.
- All 128 PNGs are linked from `index.html` (SHOT-GAL-01 link check passes; captions fail, see UX-G-06).
