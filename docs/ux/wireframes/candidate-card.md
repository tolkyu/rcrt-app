## Timeline stepper (HIST-02)

| Step | Maps to stages | Caption under step (when reached) |
|---|---|---|
| Створено | NEW | date · creator |
| В роботі | IN_WORK | date · recruiter · «Скринінг ↗Meet» |
| Співбесіда | SUBMITTED_TO_TL + TL_INTERVIEW | sub-lines: «Передано тімліду 06.10» → «Прийнято 07.10» → date ↗Meet · TL · result |
| Поліграф | POLYGRAPH | place · date/time · result · PDF icon (permitted roles) |
| Офер | OFFER | salary (if permitted) · version · outcome |
| Випробування | PROBATION | start–end · «День X з Y» · ProbationProgress |
| Пройдено | PROBATION_PASSED | date · who («Достроково» tag if early) |

- Step states: done (check, stage colour), current (filled ring + pulse off in screenshots), upcoming (hollow, muted), failed (✖ red, caption = reason). Terminal REJECTED/WITHDRAWN/PROBATION_FAILED: stepper stops at failed step; remaining steps hidden behind «—».
- Routed application: banner above stepper «Передано від Тараса Коваля (П1) · 13.10 · причина: Профіль не підійшов тімліду» with link to previous application.
- «Reschedule pending» on Співбесіда step: amber dot + «Очікує перенесення».
- Admin force move: step tagged «Примусово» with tooltip comment.
- Each step is a button: click scrolls the feed to that stage's events and filters (keyboard focusable, `aria-current="step"` on current).
- Mobile: vertical stepper, collapsed to current ±1 step, [Показати всі етапи].

- Purged: «Кандидат #1234 (видалено)», no PII, stepper + feed actor names kept ⚠ OPEN-C2.
