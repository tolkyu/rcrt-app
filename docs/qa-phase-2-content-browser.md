## BUG-CONTENT-SESSION-01 — fixed locally

- **Severity / reproduction:** Major, ADR-020 access-loss flow. Dirty published content form → PATCH 401 while cookies disappear. Server refresh returns `NEXT_REDIRECT`, documents disappear, but browser stays on editor skeleton.
- **Cause:** dirty `useLeaveGuard` passive unmount cleanup calls `history.back()`. Its popstate restores the Next router state and cancels the concurrent `router.refresh()` redirect.
- **Fix:** `ContentEditor` captures the existing imperative guard handle in layout setup and releases it during layout teardown, before passive history cleanup. Shared guard API, authorization, messages and normal Cancel confirmation are unchanged.
- **Failing before:** browser expected `/login`, received `/vacancies/<fixture>/content/edit`; three narrow unit cases reported `expected back to not be called ... called 1 times`.
- **Passing after:** 28/28 form units (engineer), desktop 16/16 including real redirect, discard and denial cleanup; mobile terminal case and all 16 scenarios verified (one test-only cursor correction).
- **Repair accounting:** one production repair. Test-harness corrections separately fixed a field-container selector, paragraph-versus-heading selector, hydration wait on link-only read surfaces, and the CANCELLED fixture constraint. No assertion was relaxed to accept the navigation bug.
