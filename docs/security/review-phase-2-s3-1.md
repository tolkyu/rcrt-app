## Findings

| #   | Sev                                   | Finding                                                                                                                                                                                                                                                                                                                                                                  | Fix                                                                                                                                    |
| --- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | Low (defence in depth)                | The `authorsAnywhere` gate lives only in the segment layout. A layout is not re-rendered on soft navigation inside its segment, and `page.tsx` does not repeat it; for a user whose role changes mid-session the page would render with `verticals = []` (no foreign data, no positions, create API still answers 403/404), so there is no disclosure, only a dead form. | Optional: `if (!authorsAnywhere(ctx.auth)) notFound();` also at the top of `NewVacancyPage` (cached `requireSession`, no extra query). |
| F2  | Low (hardening)                       | `RequestOptions.headers` is typed `Record<string, string>`: any future caller could pass a case-variant `x-csrf-protection` / `content-type`, which `Headers` would merge with the fixed value. The server rejects the result (fails closed), so it is not a bypass.                                                                                                     | Narrow the type to `{ 'Idempotency-Key': string }`, or `Omit` the reserved names.                                                      |
| F3  | Info (pre-existing, not changed here) | `oauthStartResponseSchema` uses `z.url()`, which accepts any scheme, and the login form does `window.location.assign(url)`. The value comes from our own `/api/v1/auth/google` response (Supabase), so it is not attacker-controlled.                                                                                                                                    | Optional: `z.url({ protocol: /^https$/ })` in `auth-start.ts`.                                                                         |
| F4  | Info                                  | Draft cancellation and `status=CANCELLED` pagination for another author's cancelled draft were covered only without `q`; the new test adds title/number search with every status for 8 reader types and the lost-role author (TL, HR, other vertical, no role).                                                                                                          | Done (tests added).                                                                                                                    |
