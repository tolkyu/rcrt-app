## Scope limits

This is API/library security approval, not form or mounted-query privacy approval. No current page consumes the new helper/viewer. Future ADR-020 UI integration must enforce actor/session identity boundaries, hide and evict retained documents/local editor state on confirmed read/session denial, cancel pending work, and preserve dirty-state handling. Zero GC/no-store do not themselves erase mounted state or bytes already delivered. No instantaneous mid-response role revocation, editor toolbar/paste UX, browser screenshots, bundle budget, Newman runtime or current-head CI result is claimed here.

Existing threat categories cover this slice: IDOR/private-row disclosure, stale authorization, stored XSS and sensitive-content retention. The shared threat model is unchanged under report-only ownership; future editor integration requires its own review and QA gates.
