# Security review CONTENT-CARD (VAC-08, D133, ADR-020)

Verdict: **no Critical/High; nothing blocks.** Scope: card layout, detail view, overview slots, content panel, two unit tests. Composed modules (access hook, query, schema, page) not re-reviewed.

## Checked and OK

| Area              | Evidence                                                                                                                                                                                                                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No existence leak | Detail and content use the same scope (`findVisibleVacancyOrThrow`, same `vacancy.read`), so hidden content with readable metadata only occurs in a race. `(card)/layout.tsx:23` returns the same `notFound()` as the parent layout (`[vacancyId]/layout.tsx`); missing vacancy returns `children` after the parent already 404s. |
| Swallowed failure | `layout.tsx:20` logs nothing, so no PII. Only success entries under key `vacancy` are dehydrated (`:30-32`), the failed content query never is. The error text is not sent to the client.                                                                                                                                         |
| Client denial     | `vacancy-detail-view.tsx:56-63`: content 401/403/404 sets `vacancy = undefined`, so the overview, actions, link and panel unmount. 404/403 shows the not-found card, 401 a skeleton while the hook clears the client and refreshes.                                                                                               |
| Edit link         | `vacancy-content-panel.tsx:31-36`: only state `readable` (fresh read) + `canEditContent` + OPEN/ON_HOLD. No role, creator or detail-cache logic. Server PATCH re-authorises.                                                                                                                                                      |
| Private draft     | `vacancy-overview.tsx` omits both slots for `privateDraft`; the panel returns null for status DRAFT and the link is false for DRAFT.                                                                                                                                                                                              |
| Render safety     | `RichTextView` is a typed switch over the schema union, no `dangerouslySetInnerHTML`. Documents are parsed server-side in `contentRowSchema` and client-side in `vacancyContentReadSchema`; links are https/mailto only; `Referrer-Policy: no-referrer`.                                                                          |
| List/preview      | Preview passes no slots and imports neither the hook, the panel nor `RichTextView`; no document fetch there (grep).                                                                                                                                                                                                               |

## Findings (all non-blocking)

| #   | Sev    | Finding                                                                                                                                                                                                                                                               | Fix                                                                                                                                                                                        |
| --- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| F1  | Medium | No test for the `VacancyDetailView` denial composition (`:56-63,95-105`): neither the 401 / 403 / 404 → no overview, actions or documents case, nor the 5xx → metadata + retry case. Only the hook and the panel are tested; no E2E covers a content 404 on the card. | Add a jsdom test with a mocked access state: `unavailable` notFound shows only the not-found card; `session` shows only the skeleton; `checking` with error keeps the card plus the retry. |
| F2  | Low    | Client-side `notFound` denial removes only `vacancyContent` (`use-vacancy-content-access.ts` `deny`); the metadata under `['vacancy', id]` stays in the cache and can flash in the preview or other `vacancyDetailQuery` consumers before they refetch a 404.         | In `deny`, for `reason: 'notFound'` also cancel and remove `queryKeys.vacancy(id)` (prefix, not exact).                                                                                    |
| F3  | Low    | `layout.tsx:20` swallows every error, including Next control-flow errors and DB faults, with no server log. Redirects are still surfaced via `loadVacancy` (same cached `requireSession`).                                                                            | `.catch((e) => { logger.warn({ errorName: e?.constructor?.name }); return undefined })`; no message, ids or documents. Rethrow Next control-flow errors.                                   |
| F4  | Info   | In a content-404 race, the page's `generateMetadata` may still put the vacancy title in the 404 head.                                                                                                                                                                 | Not exploitable under identical scopes; accept.                                                                                                                                            |
