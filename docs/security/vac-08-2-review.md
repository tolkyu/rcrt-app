# Security review: urgency change API (STORY-VAC-08-2 slice 1)

- Scope: commit `377c50c` on `phase-2` (`PUT /api/v1/vacancies/{vacancyId}/urgency`), spec ADR-016, D90/D94/D127, VAC-08.
- Date: 2026-11-17. Read-only review; no code changed.
- Verdict: **no Critical, High or Medium finding. Nothing blocks (D126).** Five Low / informational items and a list of missing tests below.

## Findings

| VAC08-S1 | Low (non-blocking)           | `server/services/vacancy-urgency.ts:27`    | The body is parsed a second time after the rate-limit token is spent.
